# Eternal Rain (Forge 1.20.1)

Мод делает так, что в Верхнем мире (и других мирах с небом) всегда идёт дождь.
Грозу мод отключает, обычный дождь держит постоянно, в том числе после сна.

## Сборка jar

Нужна Java 17 и интернет (Gradle скачает Forge).

    ./gradlew build        # Linux / macOS
    gradlew.bat build      # Windows

Готовый файл: `build/libs/eternalrain-1.0.0.jar`.
Положи его в папку `mods` клиента или сервера Forge 1.20.1.

## Замечания

- Дождь виден только в биомах, где бывают осадки. В пустынях и саваннах дождя не будет,
  в холодных биомах вместо него пойдёт снег (это правило игры, а не мода).
- В Незере и Энде погоды нет по механике игры.
